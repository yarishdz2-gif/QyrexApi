# Qyrex Nexus APEX v5

- Workspace Center con diagnóstico, backups de preferencias, restore y mantenimiento de UI.
- Búsqueda global con Ctrl+Shift+F y navegación por teclado.
- Borrador automático local para Create Script.
- Historial local de hasta 10 textos copiados mediante `copyLs`.
- Diagnóstico técnico copiable sin incluir credenciales.
- PWA/service worker con estrategia network-first para navegación y cache local para assets propios.
- Resiliencia offline para el shell estático sin cachear endpoints `/api/`.
- Mejora de metadata móvil/PWA.
- Corrección del campo duplicado de Key validity en Provider.
- No modifica autenticación, endpoints ni contratos existentes del backend.
